9.2.24 ANI2-G  This ME supplements the ANI -G ME. The ONU automatically creates one instance of this ME for  each PON physical port.  Relationships  This ME is associated with an ANI-G ME.  Attributes  Managed entity ID : This attribute uniquely identifies each instance of this ME. Its value  indicates the physical position of the PON interface. The first byte is the slot  ID, defined in clause 9.1.5. The second byte is the port ID. (R) (mandatory)  (2 bytes)  Lower bound transmit wavelength: This attribute specifies the minimum wavelength (lower  bound) that the ONU may transmit over all operation temperature range. Units  are nanometre. If this attribute has value 0, the lower bound transmit  wavelength is undefined. (R) (optional) (2 bytes)  Upper bound transmit wavelength: This attribute specifies the maximum wavelength  (upper bound) that the ONU may transmit over all operation temperature  range. Units are nanometre. If this attribute has value 0, the upper lower  bound transmit wavelength is undefined. (R) (optional) (2 bytes)  Actions  Get
