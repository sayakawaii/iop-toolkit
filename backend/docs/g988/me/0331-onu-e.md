Relationships  In ITU-T G.986 applications, all other MEs in this Recommendation are related directly or  indirectly to the ONU-E entity.  Attributes  Managed entity ID: This attribute uniquely identifies each instance of this ME. There is only  one instance, number 0. When the code set for the vendor_ID specified in [ATIS-0300220] is applied  to this attribute, the four characters are mapped into the 4  byte field by  concatenating the ASCII/ANSI character codes.   When the OUI is applied to this attribute, the three characters are mapped into  the 4 byte field with 0xFF assigned to the first octet.
